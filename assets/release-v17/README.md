# v17：接繩圖卡、背包快捷鍵、雙語指南與月光配樂

- C 機關：固定起點 A0，依三段實物圖卡 A0→M、M→F、F→B 接繩；每段標起點與終點。每張圖直接使用場景同源模型的正面圖。正確路線與吊籃剛好 40 kg 自動升蓋，再取鑰匙與項鍊即可前進。35 kg、45 kg 或錯誤路線不開；過重卸至40後可自動恢復。既有已升蓋存檔保留。
- C 日記、停錶、表層報告及歷史重量改為可回訪補收。D 的錄音由已開案史與出口現場取得，不再因少收 C 資料而卡住。
- 桌機 Space 開關背包，可取出持有物；文字輸入、組字、系統快捷鍵及暫停／指南／設定頁不搶鍵。手機維持直接點按。
- 中英七頁操作指南包括示範、密碼數字輪、欄位標籤與空白鍵練習。這次不宣稱整個遊戲已全面英文化。
- 配樂：貝多芬《第14號鋼琴奏鳴曲》Op.27 No.2「月光」，第一樂章 Adagio sostenuto。原2D音效以原增益保留，鋼琴依 -28 LUFS／-9 dBTP 目標調音；實際輸出數值見驗證結果。影像封包與字幕仍為 v10。MP4/AAC、WebM/Opus 衍生檔為 v12。3D 雨雷仍用已驗證的 v16。
- 樂譜由 [ScoreBase #118393](https://scorebase.org/scores/118393) 下載，對應 [PDMX](https://doi.org/10.5281/zenodo.14984509) 的 CC0、無授權衝突紀錄。來源列與 MIDI 雜湊見 music-provenance.json。PDMX 資料集：Phoebe Long 等，CC BY 4.0。鋼琴以本專案既有 scripts/render_piano_v15.swift 與 macOS 通用 MIDI 鋼琴重新離線合成，未使用商業演奏錄音。
- 重建：先由 Beethoven MIDI 合成 CAF，再執行 scripts/build_moonlight_v17.py，之後準備資產、建置網站。既有 Ravel v11 原始衍生檔留在來源分支作歷史紀錄，公開版改用月光 v12。
